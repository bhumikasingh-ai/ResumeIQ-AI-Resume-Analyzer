# 🤖 ResumeIQ – AI Resume Analyzer & ATS Score Checker

ResumeIQ is a web-based resume analyzer that compares a resume with a job description and generates an ATS-style keyword matching score.

## 🎯 Purpose

ResumeIQ helps students and job seekers understand how well their resume matches a specific job description.

## ✨ Features

- 📊 ATS-style resume score
- 🔍 Job-description keyword matching
- ⚠️ Missing keyword detection
- 💡 Resume improvement suggestions
- ✅ Resume strengths
- 📱 Mobile-friendly responsive design
- 🌐 Live GitHub Pages deployment
- ⚡ Works directly in the browser

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 🚀 How to Use

1. Open the ResumeIQ live website.
2. Paste your resume into the **Paste Your Resume** box.
3. Paste the target job description into the **Paste Job Description** box.
4. Click **Analyze Resume**.
5. Review your ATS score, matched keywords, missing keywords, and suggestions.
